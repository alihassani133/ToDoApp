# ToDoApp

ToDoApp is a simple and interactive ToDo list built with ASP.NET Core 8 MVC. It allows users to manage their tasks efficiently with features like filtering, validation, and task categorization.

## ✨ Features

- Add new tasks with:
  - **Description**
  - **Category**
  - **Due Date**
  - **Status** (e.g., Open, Completed)
- Mark tasks as completed
- Filter tasks by:
  - **Category**
  - **Due Date**
  - **Status**
- Input validation ensures required fields are filled appropriately
- Clean, responsive UI using Bootstrap

## 🛠️ Technologies Used

- **ASP.NET Core 8 MVC**
- **Entity Framework Core**
- **SQL Server**
- **HTML/CSS**
- **Bootstrap**

## 📦 Database

The application uses **SQL Server** for data persistence. EF Core handles database operations, including model creation and data validation.
